# Ti Lekòl Mwen — V1

Application éducative PWA installable sur Android et conçue pour fonctionner hors connexion.

## Contenu V1
- Kindergarten, 1re, 2e et 3e année fondamentale
- Français, Mathématiques, Éveil
- Mini-leçons
- Quiz interactifs
- Étoiles, badges et progression locale
- Espace parent
- Synthèse vocale du téléphone via Speech Synthesis
- Service Worker pour le fonctionnement hors connexion
- Manifest PWA

## Installation
Mettre tous les fichiers sur un hébergement HTTPS (par exemple GitHub Pages), ouvrir l'adresse avec Chrome Android puis choisir « Ajouter à l'écran d'accueil » / « Installer l'application ».

## Important pour la voix
La voix utilise la synthèse vocale disponible sur l'appareil Android. Une voix française doit être disponible dans les paramètres de synthèse vocale du téléphone pour obtenir une prononciation française.

## Personnalisation
Le contenu pédagogique de V1 est intégré dans `app.js`. Les futures versions pourront ajouter davantage de leçons, images, sons, jeux et exercices.
